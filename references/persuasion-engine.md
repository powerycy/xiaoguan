# 客户确信、欲望、紧迫性与成交引擎

本文件只用于完整销售判断、产品包装、陌生客户建立信任、欲望放大、紧迫性或快速成交。它指导后台推理，不要求把全部过程展示给用户。

## 内部分析顺序

`客户心理 → 真实需求 → 决策权重 → 三重确信 → 欲望 → 紧迫性 → 阻力 → 成交`

### 1. 客户心理与真实需求

从身份、经历、角色、原话、提问、反复强调、行为和决策方式中判断：

- 决策风格：结果型、控制型、证据型、关系型、共识型或价格型；可以混合，不贴人格标签。
- 显性需求：客户公开承认想解决或获得什么。
- 隐性欲望：可能想获得的收益、控制感、领先感、确定性、身份认可、轻松感或安全感。
- 核心恐惧：最怕损失金钱、时间、声誉、控制权、机会或内部支持中的哪一项。
- 信任来源：更容易被专业判断、数据、案例、第三方、熟人、亲自验证或小范围结果影响。

所有心理解释都从行为证据出发。给出最可能解释、一个替代解释和能区分二者的问题；只把最终结论压缩给用户。

### 2. 决策权重

评估结果、风险、信任、价格、控制权、实施难度、时间窗口、内部共识、替代方案和不行动成本。按“重要性 × 对决策的影响 × 证据置信度”排序。

只向用户展示最高的2–3项，并明确第一决策按钮。证据不足时使用高/中/低或区间，不为显得专业而编造精确百分比。

### 3. 建立三重确信

#### 相信销售者

根据客户的信任来源选择：相关经历、对客户处境的理解、一个具体专业判断、判断依据、过往结果、第三方证明或清晰边界。包装的目标是让客户形成“这个人懂我的问题、看得比普通销售深、说的能核验”。

#### 相信机构

只在机构影响决策时调用：品牌、资源、交付能力、服务机制、团队、客户证明和持续负责能力。客户不在意机构时不要强行介绍公司。

#### 相信产品

按照 `客户需求 → 独特机制 → 优势 → 证据 → 结果 → 与替代方案的差异` 组织。重点不是罗列功能，而是说明为什么这个优势最能击中客户的第一决策按钮。

产品事实不足时，告诉用户需要补充哪类证据，不自行发明卖点。

### 4. 放大欲望

同时寻找理性与情绪收益：

- 理性：收入、利润、效率、成本、风险降低、时间节省、资源利用或投资回报。
- 情绪：控制感、成就感、领先感、被认可、减少焦虑、抓住机会或证明判断正确。

表达任务遵循：

`当前状态 → 产品带来的变化 → 客户想要的具体结果 → 成交后的理想情景 → 不行动的代价`

只放大客户已经表达或能够通过问题验证的欲望；不要用所有卖点同时轰炸。

### 5. 建立紧迫性

优先寻找真实存在的：数量或名额限制、价格调整日期、优惠截止、供给或服务容量、项目或市场窗口、客户内部期限、外部事件，以及延迟造成的金钱、时间或机会成本。

若存在“现在不成交就没有”或“之后会涨价”的事实，把它连接到客户的第一决策因素并明确截止点。若不存在外部稀缺，使用不行动成本、客户自己的决策日期或下一验证动作，不能把预测包装成事实。

### 6. 定位阻力并成交

把异议归为信任、价值、风险、价格、时机、权限或竞争选择，找到最高权重的一项。处理后确认它是否仍是唯一阻力，并立即争取当前最高合理承诺：回答资格问题、约见、引荐关键人、验证、试单、报价确认、数量、金额、合同或付款动作。

成交动作尽量明确日期、参与人、金额、数量、范围或二选一。两个选项都必须真实可执行。

## 对用户的压缩

完整策略默认只输出：客户是什么人、什么影响决策、引导方向、如何勾起欲望、如何快速成交。用户只问一个问题时，只交付那个问题需要的结论；用户明确要话术时，才把选定方向改写成对客表达。
